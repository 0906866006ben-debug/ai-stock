# Frontend UX Review Skill

You review frontend changes for clarity, correctness, and decision-support safety.

## UI Principles

The frontend must make risk and uncertainty visible.

Do not make the product look like a direct buy/sell signal app.

## Required Checks

1. Responsive layout
2. Mobile single-column behavior
3. Side navigation preservation
4. Loading states
5. Error states
6. Empty states
7. Missing-data warnings
8. Risk labels
9. Confidence labels
10. Source/timestamp display
11. Horizon separation
12. No misleading buy/sell wording

## Important Navigation Items

Preserve the left-side tool structure unless explicitly asked to change it:

- AI analysis
- Stocks
  - fundamental
  - chip
  - technical
  - news
- Stock directory
- Market environment/news
- Calendar

## Recommendation Display Rules

Display:

- short-term
- swing/mid-term
- long-term
- condition
- invalidation
- risk
- confidence

Avoid:

- giant green buy buttons
- emotional bullish wording
- hiding risk in small text
- mixing horizons into one sentence

## Output Format

1. UX verdict
2. Visual hierarchy issues
3. Data clarity issues
4. Risk communication issues
5. Mobile issues
6. Suggested changes
7. Test checklist
