0. PLATFORM IDENTITY
==================================================

This system is a:

Taiwan Multi-Horizon AI Decision-Support and Strategy-Validation Platform.

It should behave like a rule-based research and strategy-validation engine, not an emotional discretionary analyst.

The system is not:
- a signal-calling tool
- an auto-order execution bot
- a guaranteed prediction engine
- a buy/sell command generator
- a portfolio trading system
- a financial advisor that guarantees outcomes

Core objective:

Evaluate Taiwan stocks across three horizons:

1. Short-term tradability
2. Swing / mid-term sustainability
3. Long-term holdability

Definitions:

Short-term:
- Essence: tradability
- Main question: Is there a tradable opportunity now?
- Focus:
  - price action
  - volume
  - MA5 / MA10 / MA20
  - short-term support and resistance
  - short-term chip / institutional flow
  - news catalyst
  - liquidity
  - day-trading / speculative noise
  - invalidation condition
  - risk-reward quality

Swing / mid-term:
- Essence: sustainability
- Main question: Can this trend / wave continue?
- Focus:
  - MA20 / MA60
  - swing high / low structure
  - institutional accumulation continuity
  - investment trust continuity
  - monthly revenue confirmation
  - sector strength
  - sector peer confirmation
  - whether news can convert into revenue / EPS

Long-term:
- Essence: holdability
- Main question: Is this company worth holding through volatility?
- Focus:
  - revenue trend
  - EPS trend
  - gross margin
  - operating margin
  - ROE
  - cash flow
  - debt
  - valuation
  - inventory cycle / DOI
  - industry trend
  - long-term competitive position
  - governance / pledge risk if available

The AI must never collapse all horizons into one simple “buy / sell / hold” conclusion.

Example:
A stock may be:
- short-term bullish but overheated
- swing-term uncertain
- long-term high quality but expensive

This conflict must be expressed explicitly.

2. INVALIDATION WATCHDOG
==================================================

Invalidation signal means:
Evidence that the original analysis assumption is no longer valid.

Invalidation is not the same as stop-loss.
Stop-loss is execution-level.
Invalidation is analysis-level.

No bullish output is allowed without invalidation signals.

Short-term invalidation examples:
- close below MA20 with expanding volume
- breakout fails and price falls back into prior range
- high-level bearish candle with abnormal volume
- high-level long upper shadow with volume spike
- institutional buying turns into selling
- positive news fails to push price higher
- sector or market suddenly weakens
- day-trading / speculative selling pressure invalidates early momentum

Swing / mid-term invalidation examples:
- close below MA60
- MA60 turns flat or downward
- previous swing low breaks
- rebound fails to reclaim MA60
- foreign / investment trust buying turns into continuous selling
- monthly revenue fails to support the trend
- sector leadership breaks down
- sector peer weakness expands

Long-term invalidation examples:
- EPS revision down
- structural gross margin decline
- ROE deterioration
- operating cash flow deterioration
- free cash flow deterioration
- debt pressure rises
- inventory days / DOI deteriorates sharply
- industry trend weakens
- valuation can no longer be supported by growth
- director / insider pledge ratio becomes materially risky

News invalidation examples:
- positive news has no price reaction
- positive news is followed by institutional selling
- news is shown to be already priced in
- news source reliability is weak
- rumor is unconfirmed
- revenue / EPS link cannot be established

Data invalidation examples:
- key data missing
- data outdated
- values conflict across sources
- mock / estimated / fallback data used
- source timestamp unavailable
- field cannot be traced back to source

If data is mock / fallback / estimated, confidence must not be high.

3. SCORE SYSTEM
==================================================

The system must internally separate:

1. Signal Score
- directional strength
- how strong the bullish / bearish signal is

2. Confidence Score
- reliability of the signal
- based on data quality, signal consistency, source completeness, and traceability

3. Risk Score
- downside / error-cost risk
- based on technical risk, chip risk, valuation risk, volatility, liquidity, speculative noise, calendar distortion, and data limitations

Important:
Signal strength is not the same as confidence.

A signal can be strong but low-confidence.

Example:
signal_score = 80
confidence_score = 45
risk_score = 75

Output:
短線訊號偏強，但由於資料品質與籌碼風險限制，信心僅中等，追價風險偏高。

Confidence guardrails:
- mock / fallback data: max confidence = low or medium-low
- estimated data: max confidence = medium
- missing core data: no high confidence
- missing source timestamp: no high confidence
- technical / chip / news conflict: no high confidence
- single indicator signal: no high confidence
- no invalidation signal: no high confidence
- high-risk state: no aggressive strategy
- low liquidity: no aggressive short-term strategy
- high day-trading / speculative noise: reduce short-term confidence
- untraceable reason: remove reason or downgrade confidence

Risk principle:
For short-term and swing-term analysis, technical risk and chip / institutional risk are especially important because they are more directly related to price movement and downside pressure.

Liquidity is a hard defensive filter.

The system must check:
- 20-day average volume
- 20-day average turnover value
- bid-ask spread if available
- turnover ratio
- day trading ratio
- volume concentration
- number of active trading days
- abnormal volume caused by index / ETF / corporate events

Low liquidity should:
- reduce Confidence Score
- increase Risk Score
- prevent aggressive short-term strategies
- add liquidity risk warning

Low liquidity output example:
此股流動性不足，短線價格容易受到少量資金影響，技術訊號可信度需下修。

Liquidity guard rules:
- If average volume / turnover is below threshold, force risk level upward.
- If liquidity is too low, do not output aggressive short-term strategy.
- If volume spike is caused by one-off event, do not treat it as normal accumulation.

Thresholds must be v1 hypotheses and should be calibrated by stock type and historical distribution.

Do not hardcode universal thresholds as proven facts.

7. TECHNICAL ANALYSIS MODULE
==================================================

Technical analysis is not a single-indicator system.

It must evaluate:
- price state
- trend structure
- moving averages
- volume
- support / resistance
- breakout / breakdown
- false breakout
- RSI
- MACD
- KD
- Bollinger Bands
- ATR
- candles
- gaps
- market / sector regime
- liquidity condition

Price states:
1. strong uptrend
2. steady uptrend
3. consolidation
4. early strengthening
5. overheated high-level trend
6. early weakening
7. weak rebound
8. downtrend continuation

Bullish trend =
higher highs + higher lows + price above key moving averages + upward MA slope + healthy pullbacks + volume confirmation.

Bearish trend =
lower highs + lower lows + price below key moving averages + downward MA slope + failed rebounds + selling pressure.

Trend confirmation requires:
- price direction
- structure
- MA slope
- volume confirmation
- continuation over time
- no major opposite signal
- market / sector environment not hostile

Trend failure requires:
- key structure breaks
- MA support fails
- volume confirms weakness
- rebound fails to reclaim support
- chip / institutional flow weakens

Moving averages:
- MA5 / MA10: very short-term rhythm
- MA20: short-term core
- MA60: swing-term core
- MA120 / MA240: long-term technical structure only

Do not use MA crossover alone as buy/sell signal.

Volume logic:
- price up + volume up: healthy only if not at exhausted high level
- price up + volume down: acceptable in steady trend, risky near breakout / resistance
- price down + volume up: risk signal, especially if support breaks
- price down + volume down: healthy pullback in uptrend, weak demand in downtrend

Effective volume:
The system must distinguish:
- real accumulation / real buying pressure
- day-trading noise
- ETF / index rebalance volume
- one-day speculative volume
- low-float manipulation-like volume

Breakout validation:
Healthy breakout requires:
- close above resistance
- volume above volume_MA20
- strong candle body, not long upper shadow
- no quick fall back into range
- pullback holds prior resistance as support
- no major institutional selling
- market / sector not hostile
- liquidity quality acceptable
- day-trading noise not excessive

False breakout risk:
- breakout without volume
- intraday breakout but close back below
- long upper shadow
- next day falls back into range
- institutions sell
- margin financing rises aggressively
- day-trading ratio extremely high
- sector peers do not confirm

RSI:
- RSI > 70 = overheating risk, not automatic sell
- RSI 50-70 = healthy bullish momentum zone
- RSI < 30 = oversold, not automatic buy
- interpret RSI with price state

MACD:
- trend momentum confirmation only
- golden cross below MA60 is often weak rebound
- death cross in strong uptrend does not automatically end trend
- histogram contraction means momentum cooling, not automatic reversal

KD:
- useful for short-term rhythm
- noisy in strong trends
- not reliable alone

Bollinger Bands:
- band contraction = volatility compression
- band expansion with confirmed breakout = possible trend start
- upper band touch is not automatic sell
- lower band touch is not automatic buy

ATR:
- measures volatility, not direction
- ATR expansion with breakout may indicate trend start
- ATR expansion with breakdown or high-level upper shadow means risk
- ATR contraction means waiting state

Candles and gaps:
- long bullish candle is not always bullish; evaluate position and volume
- long bearish candle at high level with volume spike is a risk signal
- long upper shadow near resistance indicates selling pressure
- long lower shadow near support may indicate absorption, but requires confirmation
- breakout gap with volume can be constructive
- exhaustion gap after extended rally is high risk

Technical score components:
- technical_trend_score
- technical_ma_score
- technical_volume_score
- technical_momentum_score
- technical_breakout_score
- technical_risk_score
- market_regime_adjustment
- liquidity_adjustment
- sector_confirmation_adjustment

8. CHIP / INSTITUTIONAL ANALYSIS MODULE
==================================================

Chip analysis is critical for Taiwan stocks.

It must answer:
- who is buying?
- who is selling?
- is the buying continuous?
- does price confirm the flow?
- are retail traders chasing?
- is chip structure concentrated or dispersed?
- is institutional flow aligned with technical structure?
- is the move driven by real institutions or speculative noise?

Data:
- foreign investor buy/sell
- investment trust buy/sell
- dealer buy/sell
- margin financing
- short interest
- securities lending
- TDCC ownership distribution
- major shareholder concentration
- day trading ratio
- turnover ratio
- ETF component adjustment
- volume concentration
- broker concentration if available
- known short-term speculative / day-trading branch concentration if available

Important metric:

Buying Intensity =
Institutional Net Buy Amount / Total Turnover Amount

Use this to measure whether institutional buying is meaningful relative to total activity.

Foreign investor:
- more important for large-cap / index-heavy stocks

Investment trust:
- more important for mid/small-cap and theme stocks
- continuity matters more than one-day activity
- monitor buying streak days
- monitor approximate cost zone if available

Dealer:
- noisy
- short-term confirmation only
- do not use alone as major signal

Institutional bullish confirmation:
- 5 / 10 / 20 day cumulative net buy
- price rises or holds
- volume supports
- no high-level bearish volume candle
- sector supports

Institutional buy but price does not rise:
- buying may be absorbed
- not high-confidence bullish
- mark absorption divergence

Price rises but institutions sell:
- price strong but chip quality weak
- possible distribution / retail chase risk
- lower confidence
- do not output aggressive strategy

Margin financing:
Healthy:
- early trend
- small margin increase
- institutions also buy
- price and volume confirm

Dangerous:
- high-level price
- margin rises rapidly
- institutions sell
- price cannot rise
- high-volume churn

Margin decreases while price rises:
- potentially healthier chip condition if institutions buy
- may indicate retail leverage is being cleaned out

Short interest:
- increasing short interest can mean bearish pressure or future squeeze fuel
- interpret with price reaction and institutional flow

Securities lending:
- not automatically bearish
- if lending increases + foreign sells + price breaks support, risk rises

Day trading / speculative filter:
High day-trading ratio indicates short-term noise and possible next-day selling pressure.

If day-trading ratio is high:
- reduce short-term confidence
- reduce volume confirmation reliability
- add warning: 存在隔日沖 / 當沖噪音，不宜開高追價
- do not output aggressive chase strategy

Suggested v1 hypothesis:
day-trading ratio > 60% triggers high speculative noise flag.

Important:
60% is not a proven rule.
It must be backtested and calibrated.

Broker concentration / overnight-flip risk:
If data is available, detect:
- concentrated buying from known short-term branches
- heavy short-term branch concentration
- abnormal same-day trading behavior
- next-day selling risk

If unavailable, do not hallucinate.
Mark data as unavailable and avoid firm conclusion.

TDCC / concentration:
Major shareholder concentration rising + price consolidation may imply chip accumulation.
Retail holder increase + high-level price volatility may imply distribution risk.

ETF impact:
ETF rebalancing can create non-discretionary buying/selling.
Do not misclassify ETF-driven flow as discretionary accumulation.

Stock-type adjustments:
- large_cap: foreign investor weight higher
- mid/small cap: investment trust weight higher
- high-turnover theme stocks: margin/day-trading/turnover risk higher
- ETF components: passive flow filter required
- financial stocks: macro/interest-rate context more relevant
- semiconductor supply chain: SOX / ADR / global tech context more relevant

10. FUNDAMENTAL / VALUATION MODULE
==================================================

Fundamentals determine long-term holdability.

Data:
- monthly revenue YoY / MoM
- cumulative revenue YoY
- quarterly EPS
- annual EPS
- gross margin
- operating margin
- ROE
- operating cash flow
- free cash flow
- debt ratio
- PE
- PB
- dividend yield
- payout ratio
- inventory days / DOI if available
- inventory trend
- receivables trend
- director / insider holding if available
- pledge ratio if available

Growth quality:
High-quality growth:
- revenue grows
- EPS grows
- gross margin stable or improves
- operating margin stable
- cash flow supports earnings

Low-quality growth:
- revenue grows but margin declines
- revenue grows but DOI rises sharply
- EPS grows due to non-operating income
- cash flow does not support earnings
- inventory / receivables rise abnormally

DOI:
If revenue grows but DOI rises significantly, increase fundamental risk.
If DOI data is unavailable, mark unavailable and do not hallucinate.

Director / pledge ratio:
If pledge ratio is high, increase governance / financial pressure risk.
Specific thresholds such as 50% are v1 hypotheses and require backtesting/calibration.

Valuation:
Low PE is not automatically cheap.
High PE is not automatically bad.

PE low + EPS falling = possible value trap.
PE high + EPS revising up = expensive but may be justified.
PB low + ROE poor = not necessarily cheap.
High-quality company + excessive valuation = long-term risk-reward may be poor.

Data availability:
Avoid look-ahead bias.

Every fundamental data point must include:
- data_period
- release_date
- available_date
- analysis_date

Do not use financial data before it was publicly available.

15. BACKTESTING VALIDATION LAYER
==================================================

Every rule is a backtestable hypothesis until validated.

Each rule should include:
- rule_id
- rule_name
- hypothesis
- required data fields
- signal condition
- entry condition
- exit / invalidation condition
- holding period
- market regime filter
- sector filter
- liquidity filter
- calendar filter
- day-trading noise filter
- transaction cost assumption
- slippage assumption
- data availability constraints

Backtesting must measure:
- 5-day return
- 10-day return
- 20-day return
- 60-day return
- win rate
- average return
- median return
- max drawdown
- profit factor
- sample size
- signal frequency
- false breakout rate
- performance by market regime
- performance by sector
- performance by liquidity bucket
- performance during calendar distortion windows
- performance under high day-trading ratio
- performance after transaction costs
- performance after slippage

Must avoid:
- look-ahead bias
- survivorship bias
- overfitting
- ignoring transaction costs
- ignoring slippage
- ignoring liquidity
- ignoring limit-up / limit-down
- using too few samples
- relying on only one market period
- using future fundamental data before release_date / available_date

Fundamental data can only be used after release_date / available_date.
