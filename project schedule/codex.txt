## High-Level Status

The Taiwan stock analysis flow now has structured Equity Research fields for Tasks 1-4, Gemini model configuration, dev-mode quota protection, and a cleaner frontend Equity Research layout.

Current key behavior:
- `/analyze/tw?symbol=2330` returns top-level Taiwan analysis plus `equity_research`.
- Top-level quick AI analysis can return `analysis_source: "ai"` when Gemini or configured fallback model succeeds.
- Equity Research can return `is_mock: false` with structured fields generated by AI.
- Some structured values may be marked `source: "estimated"` when the AI inferred them from available inputs rather than from a direct live data source.
- Mock/fallback remains available and preserves all structured fields.

## Current Meaning of "estimated"

`estimated` means AI generated or inferred the structured value from available inputs. It is not a direct live source value.

Example:
- `equity_research.is_mock = false`
- `equity_research.sentiment_data.source = "estimated"`

This means the Equity Research report is AI-generated, but the sentiment score itself is inferred rather than pulled from a real social sentiment API.

## Known Issues / Follow-Up

1. Restart backend after changes.
   - Existing uvicorn process will not use new code until restarted.

2. Gemini quota can still be exhausted.
   - `gemini-2.5-flash` has shown 429 quota errors.
   - Fallback models are tried, but they may also hit quota.

3. Grounded market research dependency.
   - `tw_market_research.py` imports `google.generativeai`.
   - If package is missing, grounded search falls back.

4. Source visibility could be improved later.
   - Current Equity Research badge uses existing fields only.
   - Future backend fields like `model_used`, `fallback_used`, `provider`, `error_reason` would make UI source labeling clearer.

5. Analyst target values may be scale-inconsistent when estimated.
   - Inspect backend prompt/data source if price targets look unrealistic versus current Taiwan stock price.

6. Security note.
   - A GitHub token appeared in conversation context earlier.
   - It should be revoked/rotated in GitHub if still valid.
