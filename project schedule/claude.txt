## Gemini Configuration

Helper file:
- `backend/app/services/gemini_diagnostics.py`

Supported env vars:
- `GEMINI_ENABLED=true/false`
- `GEMINI_MODEL=gemini-2.5-flash`
- `GEMINI_FALLBACK_MODELS=gemini-2.5-flash-lite,gemini-2.0-flash`

Default:
- `gemini-2.5-flash`

Behavior:
- `GEMINI_ENABLED=false`: skip Gemini completely and use fallback/mock.
- missing `GEMINI_ENABLED`: enabled by default for backward compatibility.
- `GEMINI_ENABLED=true`: use `GEMINI_MODEL`, then try fallback models in order.
- if all models fail: return structured fallback.

Diagnostic logs are safe:
- masked API key only
- selected model
- fallback list
- attempted/fallback flags
- error type

## What "estimated" Means

`estimated` means the AI inferred a structured field from available inputs, but the value is not a direct live API fact.

Example:
- `equity_research.is_mock = false`
- `equity_research.sentiment_data.source = "estimated"`

Interpretation:
- Equity Research report is AI-generated.
- Sentiment score is inferred by AI.
- It is not from a real social sentiment API.
