```
G0 資料就緒 → G1 因子查證 → G2 規格 → G3 實作 → G4 程式稽核(必過)
```

## 四條可複製工作流

**A. 學一個新因子**
```
用 quant-pm:先 quant-researcher 蒐證,再 factor-verifier 查證台股能否重現。
```

**B. 想法 → 規格(最重要,先別實作)**
```
用 quant-pm 把「毛利率穩定度因子」:先 factor-verifier 確認能客觀化+PIT 可算,
再 factor-spec-designer 寫成規格到 research-pipeline,先給我看過。
```

**C. 實作 + 強制稽核(核心閉環)**
```
用 quant-pm 依規格派 quant-coder 實作,完成務必 validation-auditor 稽核
程式(前視)與統計(倖存者/成本);有 Critical 回報我,先別採信。
```

**D. 驗證解讀 + 組合 + 整合**
```
(我跑完 run_value_cohort 後)用 quant-pm:performance-analyst 找有效因子,
portfolio-risk-reviewer 定組合紀律,report-synthesizer 產決策報告。
```

## 一句話記整條鏈
研究 → 查證(打假) → **設計規格** → Codex 實作 → **稽核(前視+倖存者)** → 解讀有效因子 → 組合風控 → 整合。
中間 **設計規格** 與 **稽核** 兩關永遠不能跳——它們是價值系統不變成「漂亮假回測」的唯一保險。
