## 0. 背景與定位（為什麼這份是更好的地基)

前一套 CANSLIM 我們已證明是**薄的短線動能**:A 級 1 個月中位只賺 +337 元、被 685 元手續費吃掉、12 個月反轉、組合 maxDD −72%。**根因是「短線 + 無組合建構 + 無驗證 edge」。**

這份報告是**完全不同的物種**,而且剛好補上 CANSLIM 的每一個死穴:

| CANSLIM 死穴 | 本策略如何避開 |
|------|------|
| 短線、手續費吃掉中位數 | **年再平衡**(一年動一次)→ 成本占比可忽略 |
| 無組合建構 | **等權 20–30 檔 + 年再平衡** 本身就是組合 |
| edge 薄、未驗證 | Magic Formula / F-Score / Shareholder Yield **有數十年學術樣本外驗證** |
| 高分≠抗跌 | 本策略**明確接受**長線長抱會有大回撤(2008/2022),用「品質 + 資本返還」換長期複利,而非追求低回撤 |

**定位:** 跨景氣循環的**長線(年再平衡、持有數年)價值+品質+資本返還**選股器,目標函數是「長期複利 + 避開價值陷阱」,**不是低回撤、不是擇時**。使用者已接受空頭年大回撤是「純多不停損的物理現象」。

> ⚠️ 但「報告引用的數字漂亮」≠「我方資料上成立」。本計畫的核心工作,就是把這三個因子在**我們自己的 PIT 安全、含下市股**資料上**重現**,確認 edge 真的存在於台股,而非 FinLab 的倖存者/前視偏誤產物。

## 1. 三大核心策略（值得用,逐一拆解)

### 1.1 ⭐ Magic Formula（葛林布雷 神奇公式)— 品質×便宜
- **邏輯:** 同時要「好公司」(高資本報酬)+「便宜」(高盈餘殖利率),把兩者排名相加取最低。
- **公式(台股改良版,用最近四季 TTM):**
  - 盈餘殖利率 EY = `EBIT / EV`,EV = 市值 + 長期負債 − 現金
  - 資本報酬率 ROC = `EBIT / (淨固定資產 + 淨營運資本)`;淨營運資本 = 流動資產 − 現金 − 長期投資
- **為什麼用 EBIT/EV、ROC(而非 P/E、ROE):** 排除資本結構(負債/現金)與稅率差異,純衡量「本業」的便宜度與資本效率 → 更乾淨、更難被操弄。
- **已驗證證據(待我方重現):** 美股 2000–2022 前 40 檔 CAGR 17.2% vs 大盤 8.0%(Sharpe 0.69);葛林布雷原研究 16 年 33%;歐股 MF+動能 2016–2025 +783% vs +30.5%。
- **台股盲點:** ① 循環頂部 EBIT 虛高 → ROC 看似最強卻最脆弱(需循環調整);② 交叉持股扭曲 EV;③ 必須用 TTM 不能用單一年報(資訊滯後)。

### 1.2 ⭐ Piotroski F-Score（9 分品質閘)— 避開價值陷阱
- **邏輯:** 「便宜」不一定是好貨,可能是價值陷阱(本業崩潰)。F-Score 用 9 個會計面向確認「便宜且體質在改善」。
- **9 項(每項達標 +1):** 獲利(ROA>0、CFO>0、ROA↑、CFO>淨利即盈餘品質)、安全(長債↓、流動比↑)、效率(未增發新股、毛利率↑、資產周轉↑)。
- **用法:** **硬性過濾閘——任何被 Magic Formula/Shareholder Yield 選出的股票,F-Score < 6 一律剔除**,確保只留下「便宜 + 資本報酬高 + 現金流真實 + 體質改善」的公司。
- **已驗證證據(待重現):** 美股高分組(8–9)年超額 +7.5%、多空 23%;FinLab 宣稱台股 2013– 高分組 CAGR 15.0%、低分組 4.4%(差 10.6%)。
- **台股盲點:** ⚠️ **FinLab 的台股數字必須我方重現**(它可能含倖存者/前視偏誤);F-Score 的「改善型」分項在循環頂部會虛高 → 需分產業看。

### 1.3 ⭐ Shareholder Yield（總體股東報酬率)— 比高股息更聰明
- **邏輯:** 真正的資本返還 = 現金股利 + **淨**庫藏股回購 + 淨債務減少。純高股息常是「成長耗盡的價值陷阱」(MM 定理:配息與否不創造價值;真正的訊號是管理層的資本配置)。
- **公式:** `Shareholder Yield = 股利殖利率 + 淨回購殖利率 + 淨減債殖利率`
- **已驗證證據(待重現):** 美股 82 年 top decile 13.22% vs 純高股息 top decile 11.77%(年超額 1.45%)。
- **台股盲點(最大):** 🔴 ① 台股盛行**配股(股票股利)**→ 股本膨脹、EPS 被稀釋 → 帳面「高股息」實質是稀釋;Shareholder Yield 要用**現金**股利。② 台股回購常是「買回給員工選擇權」= **沒有真的減少流通股** → 「淨」回購必須嚴格扣除再發行。③ 台股回購文化遠不如美股普遍 → 此因子在台股的有效性**最不確定,必須重現驗證**。

## 2. 多因子序列過濾架構（漏斗)

報告的核心不是單一因子,而是**序列過濾**——這正是避開「單因子追高股息/便宜陷阱」的關鍵:

```
母體
  └─[閘1] 流動性 + 保護過濾(硬排除)
        排除:金融、公用事業、KY股、TDR股、市值過小微型股、
              近8季出現≥2次警示/處置股
  └─[閘2] Magic Formula 排名(TTM:EY + ROC)→ 取最便宜+最高品質 top decile
  └─[閘3] F-Score ≥ 6 硬性過濾(剔除體質未改善者)← 避開價值陷阱
  └─[閘4] Shareholder Yield 排名 → 優選資本返還最佳者
  └─ 等權 20–30 檔
  └─ 年再平衡(+ 51/53 週的發布窗微調)
```

**重點:** 三個因子**不是加權平均**(那會像 CANSLIM 一樣互相污染),而是**序列篩選**——每一關淘汰一種缺陷。

## 3. 台股關鍵調整（執行細節,做錯就失效)

| 項目 | 必須這樣做 | 為什麼 |
|------|-----------|--------|
| 財報期間 | **TTM 最近四季**,不用單一年報 | 避免資訊滯後、抓最新獲利 |
| PIT 時點 | 一律用**公告日(filing_date)**,非結算日 | 防前視偏誤(報告特別點名) |
| 母體排除 | 金融/公用/KY/TDR/近8季≥2次警示處置 | ROC/估值對這些失真;財報風險高 |
| 配股處理 | Shareholder Yield 只計**現金**股利;股本膨脹要還原 | 台股配股稀釋 EPS |
| 淨回購 | 嚴格扣除「發給員工/主管」的再發行 | 台股回購常非真減少流通股 |
| 還權價 | 報酬/回撤一律還權息 | 除權息假跌破 |
| 稅 | 台股無資本利得稅 → 51/53 週規則改作「避開財報發布窗」用 | 報告明指台股無此稅 |
| 交叉持股 | 用 sum-of-the-parts 謹慎處理 EV | 控股公司估值扭曲 |

## 4. 嚴謹驗證原則

### 4.1 不信行銷數字,自己重現
報告引用的 FinLab 15.0% vs 4.4%、美股 17.2% 等,**一律當「待驗證宣稱」**。在我方 `pit_fundamentals.db`(PIT、含下市股、含成本)上重跑,看 edge 是否成立於台股。

### 4.2 反過擬合(報告自己強調的)
- 這三個因子**已是學術驗證過的**,所以**不要再加因子、不要調權重去追求漂亮回測**——過擬合風險在「台股調整與門檻」,不在核心因子。
- 任何**新增**因子:t-stat 必須 > 3.0(報告引用 Harvey 標準),否則拒絕。
- 多重檢定意識:別試一百種門檻挑最好的。

### 4.3 PIT / 偏誤(硬規範)
- **含下市股**(否則長線抗跌/複利全是倖存者幻覺)。
- filing_date 閘控、還權價、含成本(年再平衡成本低但仍要算)。

### 4.4 分級
**L0** 概念 / **L1** 資料研究 / **L2** 歷史回測 / **L3** paper / **L4** 小資金 / **L5** 自動化。**不得跳級。**

## 5. 分階段計畫（Phase 0–4)

### Phase 0 — 因子資料層 + 驗證引擎
- **目標:** 把 Magic Formula / F-Score / Shareholder Yield 所需欄位,從現有 `pit_fundamentals.db`(財報/現金流/資產負債)PIT 安全地算出來。
- **交付:** EBIT、EV(市值+長債−現金)、ROC 分母、F-Score 9 項、現金股利/淨回購/淨減債;reuse CANSLIM `cohort_backtest.py` 當年頻 cohort 引擎。
- **盤點:** `pit_fundamentals.db` 已有 financials/balance_sheet/cash_flow → 多數欄位可算;回購/股利明細可能要補。
- **Level:** 工具。

### Phase 1 — 單因子台股重現(關鍵:edge 在台股成立嗎)
- **目標:** 逐一在我方資料重現三因子的**前向報酬十分位**(年頻、含下市、含成本)。
- **decision gate(每個因子):** top decile 是否顯著贏 bottom decile + 贏大盤?**特別檢驗 F-Score 能否重現 FinLab 宣稱的 ~10% 差距**;若重現不出來 → 該因子在台股存疑,降級。
- **Level:** L2。**這一步決定整個系統值不值得做。**

### Phase 2 — 序列過濾組合回測
- **目標:** 把漏斗(閘1→閘4)組起來,等權 20–30 檔、年再平衡,跑 2008–2025。
- **報告:** CAGR、MaxDD、Calmar、Sharpe、**vs TAIEX 逐年**、**最長落後期(underperformance stretch)**。
- **decision gate:** 長期 CAGR 顯著贏 TAIEX(報告期待),且回撤在「純多長抱」可接受範圍(會是 −40~−50%,非 −72%,因有品質閘);落後期不超過心理可承受。
- **Level:** L2 → L3。

### Phase 3 — 台股穩健性 + 子期間
- **目標:** 驗證對「台股調整」的敏感度:排除/納入金融、配股還原方式、F-Score 門檻(6 vs 7)、產業中性、子期間(多/空/盤整)、±20% 參數。
- **decision gate:** 結論不因單一調整崩潰 → 穩健;否則標記脆弱。
- **Level:** L2/L3。

### Phase 4 — Paper 組合 + 上線紀律
- **目標:** 年再平衡的實際執行(選股清單、流動性可成交性、發布窗避開)。
- **交付:** 「三有加一」(有預期、有底線、有計劃、一執行)+ 年再平衡 SOP + paper 1–2 個再平衡週期。
- **Level:** L3 → L4。

## 6. 風險與盲點（先講在前)

1. 🔴 **FinLab 台股數字未必可信** → Phase 1 重現是成敗關鍵,別假設 edge 存在。
2. 🔴 **台股是動能/散戶主導市場** → 價值+品質因子在台股**可能落後更久**(美股的有效性不必然移植);要看最長落後期。
3. 🔴 **純多長抱 = 大回撤** → 2008/2022 仍會 −40~−50%;這是設計接受的代價,但要讓使用者「事前」看清楚回撤幅度與落後年數,而非事後崩潰。
4. 🟡 **Shareholder Yield 在台股最不確定**(配股稀釋 + 回購文化弱)→ 可能要降權或只用現金股利+減債兩項。
5. 🟡 **循環股品質陷阱**(高 ROC/EBIT 在循環頂)→ 需循環調整或產業中性。
6. 🟡 **樣本:單一台股歷史 ~15 年、年頻 → 獨立樣本少**;別過度自信,逐年逐 regime 列表。
