**作者視角:** 華爾街量化交易員 / 風控委員

**最高紀律:** 分級制 L0 概念 → L1 資料 → L2 回測 → L3 paper → L4 小資金 → L5 自動化,**不得跳級**。任何因子在我方 PIT + 含下市 + 含成本資料上驗證通過前,一律是 hypothesis。

## 0. 你是誰(投資者畫像 = 系統設計的邊界條件)

任何機構建系統前先寫 IPS(投資政策聲明書)。你的:

| 約束 | 系統設計含義 |
|------|-------------|
| **無法一直看盤** | 再平衡頻率必須是「年頻為主、月頻檢查」;任何需要日內/日頻決策的策略一律不合格 |
| **大波段、低頻、少而精** | 優化目標是**精確度**(少數高把握標的),不是訊號數量或總 PF |
| **已接受純多長抱的大回撤** | 不做擇時、不停損;風控放在**組合建構層**(分散、等權、單檔上限),不放在訊號層 |
| **怕錢浪費在垃圾股** | 流動性閘 + F-Score 品質閘 + 停滯股剔除是硬性前置過濾,永遠在評分之前 |

**結論:長線價值+品質+資本返還系統是你唯一該全力做的核心。** CANSLIM 動能系統已在 15 年回測證明:訊號層有動能 edge(PF 1.16)但**組合層不可投資**(CAGR 0.4%、maxDD −72%)——正式封存為研究資產,不再投入(教訓已萃取:成本敏感、空頭年集中虧損、無組合建構)。

## 2. 總體架構:一個核心,沒有衛星(現階段)

```
                    ┌─────────────────────────────┐
                    │   核心:長線價值組合 (100%)    │
                    │   Magic Formula → F-Score 閘  │
                    │   → Shareholder Yield 排名    │
                    │   等權 20-30 檔、年再平衡      │
                    └─────────────────────────────┘
   進場前的唯一工作:Stage 1-3 驗證通過
   日常的唯一工作:月跑篩選器看觀察名單 + 年一次再平衡
```

機構常做 core-satellite(核心+衛星),但你的時間預算不支持兩套系統。**動能衛星等核心上線一年後再議**——而且只有在你「想要」而非「需要」時。

## 3. 路線圖(七個 Stage,每個都有決策閘門)

### Stage 1 — F-Score 全量驗證【本週,你按一個鍵】
- **動作:** `python -m backend.scripts.run_value_cohort --factor fscore --include-delisted --max-staleness-days 10`(2011-2025 全量,預估數小時)。
- **看什麼:** `artifacts/value_cohort/value_cohort_fscore_summary.md` 的決策閘門 — 高分組(F≥8)是否在 12 月淨報酬上**穩定**贏低分組(F≤2)與 TAIEX?逐年一致嗎?在大/中/小市值內都成立嗎?
- **決策閘門:**
  - 重現出明顯正差距(方向對、多數年份成立)→ 進 Stage 2。
  - 差距為零或負 → **FinLab 數字不可信,F-Score 在台股降級**;回頭只用它當「避雷閘」(剔除 F≤2)而非選股因子,並重新評估整個漏斗。
- **量化交易員的提醒:** 不要因為差距「只有」5% 而失望——年化 5% 的穩定因子差距在機構是值錢的;要看的是**一致性**,不是單一數字大小。

### Stage 2 — 三因子重現 + 序列漏斗組合回測【1-2 週】
- **2a:** 跑 `--factor magic` 與 `--factor sy` 兩個 cohort(引擎已支援,零新程式)。SY 是台股最不確定的因子(配股稀釋+回購文化弱)——重現不出來就只留「現金股利+減債」兩項或降權,**不要硬塞**。
- **2b(新程式):** 序列漏斗組合回測 — 母體 →流動性/保護閘 → Magic Formula top decile → F-Score ≥6 硬閘 → SY 排名 → **等權 20-30 檔、年再平衡、2011-2025**。輸出:CAGR、MaxDD、Calmar、Sharpe、逐年 vs TAIEX、**最長落後期**(連續跑輸大盤幾年——這是你心理上最重要的數字)。
- **決策閘門:** CAGR 顯著贏 TAIEX、MaxDD 在 −40~−50% 內(可接受的純多物理現象)、最長落後期 ≤ 你能忍受的年數(誠實回答:3 年你撐得住嗎?)。

### Stage 3 — 穩健性測試【1 週】
- 參數 ±20% 敏感度(F 門檻 6 vs 7、持股數 20 vs 30、Magic decile vs quintile)。
- 子期間:2011-2015 / 2016-2020 / 2021-2025 分段;空頭年(2011/2015/2018/2022)單獨看。
- 還權價誤差量化:抽 10 檔高配息股比較原始價 vs 還權價的報酬差,確認結論方向不變。
- **決策閘門:** 結論不因任何單一調整翻轉 → 系統穩健;某調整讓 edge 消失 → 標記脆弱、回 Stage 2 診斷。**禁止**在這一步挑最漂亮的參數組合(那是過擬合,Harvey t>3 紀律)。

### Stage 4 — 篩選器校準【數天】
- 把 `value.screener` YAML 的 v1 假設門檻(EY 0.10、ROC 0.20、SY 0.05、等級分數線)換成 **Stage 1-3 校準值**(例如:cohort 裡真正帶 edge 的 F-Score 分界、EY/ROC 的有效十分位邊界)。
- 籌碼面/技術面權重用 cohort 資料檢驗:法人持續性高的組 12 月前向報酬真的比較好嗎?不好就降權重或歸零——**篩選器的每一分權重都要有資料背書**。

### Stage 5 — Paper 組合【1-2 個再平衡週期 = 3-12 個月】
- 用驗證過的漏斗產出第一份 20-30 檔等權名單,記錄於 repo(`Docs/portfolio/paper_YYYY.md`):每檔的進入理由(因子數值)、權重、基準日。
- 寫**再平衡 SOP**:每年固定月份(避開財報發布窗)、汰換規則(跌出漏斗即出、新進前 N 即入)、流動性確認(目標金額 < 當日成交額 X%)。
- 每月跑一次 `run_value_screen` 對照 paper 組合 — 不動作,只記錄偏離與心理反應。**這一步在測試的是你,不是系統。**

### Stage 6 — 自動化(配合「無法看盤」)【與 Stage 5 並行】
- 排程:每週 `refresh_data.py`(資料新鮮)+ 每月 `run_value_screen`(觀察名單)→ 報告透過現成 Telegram bot 推送。
- 監控告警:資料停更 N 天、持股中出現 F-Score 急降或停牌 → 推播。**系統替你看盤,你只看月報。**

### Stage 7 — 小資金實彈(L4)【paper 通過後】
- 條件:Stage 5 至少一個完整再平衡週期、行為與 paper 一致、你睡得著。
- 規模:總資金的小比例起步(你自己定,建議能承受 −50% 而不影響生活的數額)。
- 一年後檢討:實際 vs paper vs 回測的三方對照(滑價、可成交性、行為偏差)→ 通過才談加碼。

## 4. 組合層風控(這次不能再缺席)

CANSLIM 的 −72% 教訓 = **沒有組合建構的訊號系統不是系統**。本系統的風控全部內建在組合層:

1. **分散:** 等權 20-30 檔(單檔 3.3-5%),單一產業 ≤ 30%(粗分類即可,別過度工程)。
2. **品質閘 = 隱性風控:** F-Score ≥6 + 流動性閘 + 停滯剔除,結構上排除最會歸零的標的。
3. **回撤預算(事前簽字):** 空頭年預期 −40~−50%、可能連續 2-3 年跑輸大盤。**把這行字印出來貼在螢幕邊**——事前接受的回撤是成本,事後驚慌的回撤是災難。
4. **不做的事:** 不停損(年頻系統停損=雜訊交易)、不擇時(已證明 MA 濾網救不了還賠 CAGR)、不加槓桿、不因三個月跑輸就改參數。
5. **唯一的逃生門:** 系統性失效判定(見 §5 kill criteria),不是價格觸發。

## 5. 紀律守則與 Kill Criteria

**禁止事項(寫死):**
- 驗證未過的因子不進漏斗;權重門檻不在 OOS 上調;新增因子需 t-stat > 3。
- 不得跳級(L2 沒過不准 paper,paper 沒過不准實彈)。
- 篩選器輸出永遠是觀察分級,不是買賣指令;`本分析僅供參考,不構成投資建議。` 保留。
- 單一年度績效(好或壞)都不構成改系統的理由。

**Kill criteria(滿足任一 → 停止實彈、回 L2 診斷):**
- 實彈組合連續落後 paper 組合 >10%(執行出問題)。
- 滾動 3 年因子差距(F 高低分組)歸零或翻負(edge 衰減)。
- 資料管線斷裂無法修復 PIT 正確性。

| Stage | 內容 | 時間 | 等級 | 閘門 |
|-------|------|------|------|------|

**最快路徑:約 1 個月到 paper、6-12 個月到小資金。** 任何更快的承諾都是在騙你。

## 7. 一句話總結

> 你已經把最難的部分做完了(PIT 資料 + 因子層 + 驗證引擎)。接下來不是寫更多程式,而是**按下驗證鍵、誠實面對結果、然後用一年的耐心把回測變成習慣**。量化交易的超額報酬,一半來自因子,一半來自「別人撐不住的時候你照表操課」——而你的表,就是這份文件。
